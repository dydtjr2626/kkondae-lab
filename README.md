# 꼰대연구소 (kkondae-lab)

- 배포 주소: https://kkondae-lab.onrender.com
- GitHub 저장소: https://github.com/dydtjr2626/kkondae-lab

주제 3가지(직장 / 학교·동아리 / 가족·명절)마다 24문항 풀에서 회차마다 12문항을 뽑아 출제하는 꼰대력 테스트입니다. 결과는 꼰대력 %, 5단계 등급, 6가지 유형(5가지 꼰대 유형 + 20% 미만일 때의 '자유로운 영혼형')으로 나옵니다. 2인 방(방 코드 / 랜덤 매칭)에서 상대의 선택을 맞히고, 결과를 동시에 공개해 비교하고 채팅할 수 있습니다.

## 사용법

1. 이름을 입력하고 "새 방 만들기"를 누르면 6자 방 코드가 자동 생성됩니다. 코드를 친구에게 전달하세요.
2. 또는 "랜덤 채팅"으로 최대 2분까지 짝을 찾을 수 있습니다.
3. 둘 다 12문항을 마치면 3초 카운트다운 뒤 결과가 공개됩니다.
4. "다시하기"를 누르면 다음 회차가 진행됩니다.

## 실행

Node.js 18 이상이 필요합니다. 별도 설치할 패키지와 API 키는 없습니다.

```
node server.js
```

실행 후 http://localhost:2500 에 접속하세요.

## 환경 변수 (선택)

| 이름 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `2500` | 서버 포트 |
| `HOST` | `127.0.0.1` | 바인딩 주소 (`PORT`가 지정된 배포 환경에서는 자동으로 `0.0.0.0`). 주의: `PORT`를 지정하면 HOST 기본값이 `0.0.0.0`(외부 접속 허용)이 되니, 내 PC에서 PORT를 바꿔 실행할 때는 `HOST=127.0.0.1`을 함께 지정하세요. |

## 구성

- `kkondae.html` — 화면
- `server.js` — 정적 파일 + 방/채팅 API, 변경 알림(SSE), 랜덤 매칭
- `logo.png` — 로고 이미지
- `package.json` — start 스크립트, Node>=18
- `.gitignore` — 제외 목록
- `data.json` — 방/채팅이 저장될 때 생성되는 데이터 파일 (git 제외)

## 배포 (Render)

1. GitHub에 push 후 [Render](https://render.com) → New → Web Service 에서 이 repo 연결
2. Runtime: `Node`, Build Command: `npm install`, Start Command: `npm start`
3. Deploy 후 발급된 `https://....onrender.com` 주소로 접속

> 무료 플랜은 일정 시간 접속이 없으면 잠들어 첫 접속이 수십 초 걸릴 수 있고, 재시작·재배포 시 `data.json`의 방/채팅 기록이 초기화됩니다.
>
> 공개 repo를 직접 연결한 방식이라 자동 배포가 되지 않습니다. 코드를 고친 뒤에는 Render 대시보드에서 Manual Deploy → Deploy latest commit을 실행해야 합니다.

## 한계 (과제용 데모)

- 로그인/인증이 없습니다. 방 코드를 아는 사람은 누구나 그 방의 내용을 읽고 바꿀 수 있습니다. 직접 입력한 짧은 코드(3~5자)는 추측될 수 있으니 "새 방 만들기"의 6자 코드를 권장합니다.
- 요청 횟수 제한(rate limit)이 없습니다. 대신 문서 크기 2KB, 방당 메시지 최근 200개, 방당 플레이어 20명, 서버 전체 방 150개, 실시간 연결 300개, 랜덤 대기 100명으로 상한을 두었습니다. 상한에 도달하면 새 방 생성이 거절됩니다.
- 랜덤 대기열은 메모리에만 있어 재시작하면 사라집니다. 짝이 정해진 뒤 상대가 창을 닫으면 혼자 남을 수 있습니다.
- 탭을 닫기만 하고 "나가기"를 누르지 않으면 방이 남습니다(재시작 시 정리).
- 비속어 필터는 단어 목록 방식이라 우회될 수 있습니다.
- 화면 글꼴은 Google Fonts를 외부에서 불러옵니다.
